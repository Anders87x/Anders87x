## 👨‍💻 Sobre mí

Soy **AnderCode**, desarrollador de software, instructor y creador de contenido enfocado en construir soluciones reales y enseñar el proceso detrás de ellas.

- 🚀 Desarrollo **aplicaciones Full Stack**, APIs y plataformas web.
- 📱 Creo aplicaciones móviles con **Flutter**.
- 🤖 Exploro **IA, agentes, automatización, Ollama y OpenAI**.
- 🎓 Creo cursos y contenido práctico de programación.
- 📚 También desarrollo proyectos editoriales y productos digitales.
- 🌎 Desde Perú, construyendo para la web.

> **Mi filosofía:** aprender construyendo, probar cada fase y convertir ideas en software que funcione.
